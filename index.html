Questions

Short answers to the common ones.

Does it need an internet connection?

No. All tools work offline. The only exception is HTML to PDF when you enter a web address, because the page has to be fetched.

What happens after the 90-day trial?

The tools pause and a message explains that a licence is needed. You can still open the dashboard and see your history.

Can I convert password-protected PDFs?

Yes, once you have removed the password with the Unlock PDF tool. You need to know the password.

Does PDF to Word work on scanned documents?

It works best on PDFs that contain real text. Scanned pages are kept as images, because text recognition is not included yet.

Where is my data stored?

Accounts, the trial date and your statistics are stored on your own PC in the PDFStudio folder inside your user profile.
